In the repository at `/app`, start the app for local development (API and both
front ends). Use these development values; they are not secrets:
`LLMOXIE_BASE_URL=http://localhost:4000`, `LLMOXIE_API_KEY=dev-key`,
`DATABASE_URL=postgres://llteacher:dev@localhost:5432/llteacher`. Placeholder
values are fine for the WorkOS and key variables. Start each server in the
background and report.
