# Bugs
* [BLIND_INDEX_KEY drift silently forks user accounts](blind-index-key-drift-forks-accounts.md) - Login matches pre-provisioned users by HMAC(email, BLIND_INDEX_KEY); a different key per developer or after rotation misses the match and silently creates a duplicate user with no memberships.
* [Truncated or non-replayable assistant turns poison chat idempotency](partial-stream-persisted-as-complete.md) - A stream that errored after some text was persisted as a complete answer and replayed forever; a related fallthrough returned 409 in_progress for already-finished turns, so retries never recovered.
* [Client-supplied chat history allowed system-message injection](client-history-system-message-injection.md) - /api/chat validated only the last message; earlier client-sent history went to the model unchanged, so a client could inject a real system message that was never persisted or visible to instructors.
* [Interrupted CREATE INDEX CONCURRENTLY leaves an INVALID index that IF NOT EXISTS skips](invalid-concurrent-index-skipped.md) - migrate.ts runs CONCURRENTLY index builds outside drizzle's transaction relying on IF NOT EXISTS; an interrupted build leaves an INVALID index that satisfies IF NOT EXISTS forever, so retries never rebuild it.
* [ON DELETE SET NULL conflicted with a CHECK constraint on grades](grader-fk-set-null-vs-check.md) - grades.grader_membership_id ON DELETE SET NULL broke grades_grader_consistency_chk: Postgres runs SET NULL as an UPDATE, the CHECK rejects it, so deleting a grader membership failed; switched to RESTRICT.
* [Org deletion bypasses RESTRICT FKs because of cascade ordering](org-delete-cascade-order.md) - Deleting an organization succeeds and cascades grades and LLM logs away even though user/submission paths RESTRICT, because the org's direct cascade FKs fire first; a reviewer's opposite claim had to be reverted.
* [memberships[0] from an unordered query picked an arbitrary course](unordered-memberships-first-row.md) - Chat turns without a conversationId were filed under authContext.memberships[0] from a query with no ORDER BY, so the course was arbitrary and could change between requests; fixed by sending a resolved courseId.
* [WebR install.packages silently failed; tidyverse never loaded](webr-source-package-install-fails.md) - WebR's R runtime cannot build source packages, so install.packages for ggplot2/dplyr/tidyr failed and per-package catch hid it; fixed with webR.installPackages from the WASM binary repo.
* [Chat surfaces rebuilt and re-scrolled on every streamed token](chat-rerender-per-token.md) - useChat re-renders per chunk; unmemoized message building for both surfaces and a scroll effect keyed on array identity made work scale with token rate; fixed with memo, throttle, and length-keyed scroll.
* [Resubmitting after grading leaves the grade describing replaced work](grade-stale-after-resubmission.md) - submissions is one mutable row per conversation; resubmit only overwrites submittedAt, so an existing grade keeps pointing at the row with no staleness flag or grader notice. Open (#258), tied to attempt-model decision #250.
* [Release logs hid Pulumi errors via /dev/null and command substitution](pulumi-bootstrap-errors-swallowed.md) - First production release failures showed only exit 1: bootstrap sent pulumi up stdout to /dev/null, and after that fix an outer $(...) still captured it; diagnostics now go to stderr, stdout carries only the ECR URL.
* [First AWS production release blockers: new stack refresh and missing service-linked roles](first-production-release-blockers.md) - Bringing up production hit a config refresh failing on a stack with no deployments, then missing ELB/RDS/ECS service-linked roles (ecs:RunTask could not assume the ECS role); all now created in account bootstrap.
* [Overdue auto-submit sweep: per-org cap vs per-invocation budget, and abort-on-one-org](overdue-sweep-budget-and-races.md) - The hourly overdue auto-submit sweep had a per-org cap against Cloudflare's per-invocation subrequest limit, aborted every org on one failure, and raced restarts onto soft-deleted conversations; fixed in PR #432.
* [Hint suppression tests must wait for initial history](hint-test-initial-hydration-race.md) - The hint button can render before initial section history arrives; suppression tests need a visible hydration precondition so history cannot replace their streamed reply.
